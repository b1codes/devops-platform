devops-platform

Hello from devops-platform

A standardized, secure deployment engine for AWS workloads. Reusable Terraform modules and GitHub Actions workflows, built on the Golden Path methodology.

[S3]

Secure Object Storage

This page is served from a private S3 bucket with SSE encryption and all public-access controls enabled.

[CF]

CloudFront Distribution

Delivered via CloudFront using Origin Access Control (OAC), HTTPS enforced, with edge caching for low-latency delivery.

[TF]

Terraform Provisioned

All infrastructure was created with the b1c-secure-bucket module and a CloudFront distribution defined in examples/static-site/main.tf.

[GH]

OIDC Deployments

Site content is deployed via the reusable aws-static-site.yml workflow using AWS OIDC authentication. No static credentials.

Quick deploy command
git clone https://github.com/B1Codes/devops-platform
cd devops-platform/examples/static-site
terraform init && terraform apply
